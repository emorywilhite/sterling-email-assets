# Sterling email assets

This repo is frozen. It holds the images already used in sent newsletters. A sent email points at https://raw.githubusercontent.com/emorywilhite/sterling-email-assets/main/ plus the filename. Do not add files. Do not rename or delete existing files, because sent emails still use that URL.

New images go in the website repo at public/email/, and a sent email should point at https://thesterlingcouncil.org/email/ plus the filename.

Campaign copy and the HTML source stay in sterling-council. A few HTML files are sitting in this repo now. They are not its job, and new campaign HTML should not be added here.
