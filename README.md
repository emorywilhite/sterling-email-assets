# Sterling email assets

This repo is the public host for images inside sent newsletters. A sent email points at https://raw.githubusercontent.com/emorywilhite/sterling-email-assets/main/ plus the filename. Add a new file under a new name. Never rename or delete one. Campaign copy and the HTML source stay in sterling-council. A few HTML files are sitting in this repo now. They are not its job, and new campaign HTML should not be added here.
